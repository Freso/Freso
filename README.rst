=============================
 💥 GitHub funds Genocide 💥
=============================

GitHub’s owner, `Microsoft`_, is “perhaps the most complicit tech company in
Israel’s illegal apartheid regime and ongoing genocide against 2.3 million
Palestinians in Gaza.” As such my use of GitHub will be minimised as much as
possible, and any projects I own or control myself I will work to move to other
code forges, notably `Codeberg`_. If you’re looking for a project of mine that
used to be here and isn’t anymore, check to see if it can be found on `my
Codeberg profile <https://codeberg.org/Freso>`_.

This sucks! What can I do?
--------------------------

* If you’re doing GitHub sponsorships, see if you can fund those projects/creators
  off of GitHub (e.g., do they have a `Liberapay`_?).

* If you’re taking GitHub sponsorships, see if you are able to move that income
  to a different platform (like `Liberapay`_).

* If you’re hosting projects on GitHub, check if it’s possible to move them away
  from GitHub (e.g., to `Codeberg`_).

  * If you’re not able to move off of GitHub entirely, try to limit the amount
    of dependency on GitHub/Microsoft technologies.

* If you’re working for/with/under `Microsoft`_ (e.g., on GitHub), sign the
  `internal worker petition <https://noaa.cc/petition>`_ and
  `join the No Azure for Apartheid campaign <https://noaa.cc/join>`_.

* Educate yourself and see the BDS Movement’s own bullet list of action points
  by reading https://www.bdsmovement.net/microsoft
